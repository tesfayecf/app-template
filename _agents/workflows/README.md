# Workflows

| File | Use it to |
| --- | --- |

| [add-a-frontend-feature.md](add-a-frontend-feature.md) | Add a feature slice (page, service, query keys) to the web app |
| [add-a-decision-record.md](add-a-decision-record.md) | Record a significant decision |
| [run-the-quality-gate.md](run-the-quality-gate.md) | Run the backend tests, frontend checks and docs check before a commit |
| [deliver-a-change-by-pull-request.md](deliver-a-change-by-pull-request.md) | Branch, commit, check and open a pull request |
